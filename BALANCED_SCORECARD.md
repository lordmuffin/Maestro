# Balanced Scorecard Dashboard

**Objective:** Prevent gaming by looking at Speed and Quality simultaneously.

## Metrics Legend

| Metric | Your Data Source | The "Good" Signal |
|---|---|---|
| **Flow Velocity** | GitHub "Done" Count (Last 7 Days) | Stable or Increasing. |
| **Change Failure Rate** | % of Deploys followed by Azure Alert | **< 10%**. If > 10%, stop building new features. |
| **Flow Efficiency** | (Active Time / Total Time) | Increasing. (Means less "Distraction/Wait"). |
| **Value ($)** | Sum of "Value" fields from Done tickets | **> $0**. (Proves you aren't just shipping "chores"). |
